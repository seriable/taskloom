# 可选中文项目工作台

在正式 SQL host 配置 `console:true` 后，`/console` 提供项目工作台。
用户输入租户、项目和现有 Bearer，或通过宿主显式配置的 OIDC/PKCE 登录。
页面不发行身份或修改角色；每个 API 请求仍校验 SQL membership 和权限。

目前可提交/检查队列、读取共享运行/工作流/会话、检查诊断、对精确 ticket
记录审批，以及使用宿主开启的个人记忆和 `no-tools-v1` 私有会话。共享记录
与个人会话分别显示；用户不能通过输入 owner 读取别人的私有数据。

Bearer 仅保留在本页内存，SSO token 不返回页面 JavaScript。退出连接或更换
身份时，令牌、读取结果、私人草稿、记忆编辑输入和事件观察都会清除。
后台旧响应带连接 generation 检查，不渲染到新身份。远端内容只通过
`textContent` 显示，不作为 HTML、脚本或操作指令。

## 有界事件观察

在共享记录中选择运行或工作流的 ID，展开“实时观察”，点击“观察事件
30 秒”。页面按服务端 `next` 游标每秒读取最多 200 条事件，校验游标增量，
最多显示最近 500 条且事件正文总量不超过 1 MiB，并显示本视图省略数量。
源运行的持久化日志不被截断。

观察总时限 30 秒；网络请求也有超时和 4 MiB 流式读取上限。每次读取重新
认证，遇到拒绝/错误会停止，切换身份、离开页面或主动点击停止会中断请求。
该视图只读取已保存的记录，不恢复运行、不调用模型、不自动外发遥测。
事件可能包含项目共享的模型/工具内容，仅应在被授权的设备上查看。

当前是有界游标轮询，不宣称 durable SSE、跨浏览器订阅恢复、全局原子事件
快照或生产实时延迟 SLO。项目指标通过显式点击读取；Trace 与评测继续使用
既有诊断接口/视图，尚无统一的跨项目管理后台。

取消或超时不保证服务端未处理原提交；页面会提示检查原 ID。审批只保存
决定，需要显式恢复，不能从 UI 状态推导工具已执行或未知效果已解除。

## 本地验收边界

本轮使用真实浏览器和 SQLite host 验证：Alice 创建并完成一轮 offline
私有会话、Bob 无法读取相同 ID、共享运行列表不出现私有 child、个人记忆
scope 来自认证用户、观测读取不派发服务、390px 布局，以及退出/切换身份
后的草稿与凭据清理。相关 fixture 未调用远程模型。

OIDC/PKCE 的本机 fake IdP 测试和生产 Secure cookie/CSP 参数测试另见
[登录说明](login-service.md)。这不代表真实外部 IdP、TLS 终端或生产部署
已经验收。事件观察已用真实浏览器核对11条保存事件及cursor=11、任务完成后
停止、断开后清空事件与凭据；显式语义能力开关和空owner scope也已观察。
浏览器退出竞争的epoch guard经过代码审查，未声称实际复现过全部竞争时序。
后续改变这些源码时仍需对应重新验收。
