# 文档语言约定

仓库根目录的 `README.md` 是默认入口，使用中文；`README.en.md` 保留完整
英文入口。两个文件顶部和底部互相链接，新增功能、安装方式、限制和安全
边界需要同步更新。代码名、API 名、feature 名、错误类型和命令保持原文，
避免翻译后无法复制。

当前技术文档仍以英文为主。不会在没有维护能力时复制约四十份文档造成
双份漂移；后续按用户入口优先级翻译运行时、应用、检索、MCP、记忆和部署
指南，并在对应页面提供中文/英文链接。技术文档的英文版本是规范文本，
README 的中文内容负责产品入口和边界说明。

语言切换：

- 中文入口：[README.md](../README.md)
- English entry: [README.en.md](../README.en.md)

提交 README 时请检查两个入口的本地链接、安装命令、版本说明和限制是否
一致。不要把 README 中的有限模型评测、引用匹配或框架对照写成普遍事实
正确性、性能排名或生产可用性保证。
