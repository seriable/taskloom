## 使用与迁移边界

这是早期开放源码框架，适合按明确模型、权限和部署环境进行受控集成。
默认单任务库保持最小功能；运行时、应用、SQL 服务均需显式启用。
本地操作员 UI 与带身份的项目 JSON 服务是不同入口；多人服务拒绝固定
私有记忆配置，未提供私有记忆 API，不能宣称具备多人记忆管理界面。

新上下文/检索选项默认关闭并省略 JSON，保留旧身份；显式开启改变冻结
契约，旧运行须保留原配置，索引内容改变须显式重建。Rust 完整结构体
字面量可能需要补新增字段，见[上下文保留](context-retention.md)及
[检索 profile](retrieval-quality-profile-v6.md)。SQL 升级要求静止窗口，
不是滚动升级承诺。

预算在派发前持久化；未知模型用量保留，未知外部效果不静默重试。
外部服务不参与 SQL 事务，不能据 fencing 推导出通用 exactly-once。
原文引用和同模型审稿均不能保证事实正确；短查询、跨语言和其他领域
需要自己的检索校准。有限负载结果不能推出生产规模吞吐或持续可用性。

阿里套餐由用户声明每月 45,000 次；本地请求分配按实际 HTTP 尝试计数。
零 token 现金计价表示选定预付费路径的配置，不代表免费服务、账单核实
或未知用量为零。套餐余额与服务商计费倍率未核实，凭据不进入源码。

本次交付仅发布源码至 GitHub main；不覆盖已有标签/附件，也不发布
crates.io 包。使用新增功能应从当前 checkout 安装，历史标签仍可复现
其当时版本。
